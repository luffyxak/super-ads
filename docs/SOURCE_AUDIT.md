## Scaffold regression

`python3 -m unittest discover -s tests -p test_scaffold.py -v` exercises the
original CLI in disposable copies. The initial eight tests produced 12
failing assertions across subtests. A second invocation wrote into the
existing directory, including when different names produced the same
normalized slug. Raw brand and product strings entered HTML and Markdown.
Existing symlinks were followed. Blank, multiline and oversized fields
also reached file creation. CTA starts measured 10.3s, 20.6s and 6.9s for
15s, 30s and 10s formats respectively.

The 11 current tests pass. The CLI reserves a new output directory,
keeps edited projects when a slug is occupied, and rolls back a partial
scaffold on write failure. It treats display fields as text, caps their
length and rejects line/control characters. It retains the familiar
slug for ordinary names and uses a bounded hash fallback for long or
non-ASCII-only labels. The CTA starts at `max(duration × 0.8, duration − 3)`
and holds to the end in the storyboard, shot list and HyperFrames scaffold.

## Runtime and third-party boundary

Baseline host tools were Python 3.14.5, Node 26.13.0, npm 11.20.0, FFmpeg
8.1 and Codex CLI 0.166.0. The legacy lock pins HyperFrames 0.9.15 and GSAP
3.15.0. npm's initial audit found one high-severity dependency entry for
Undici 7.25.0 and a moderate entry for HyperFrames through that dependency.
The lock overrides Undici to 7.30.1. The follow-up
`npm --prefix examples/hyperframes-diwali-8s audit --omit=dev` found zero
reported vulnerabilities.
