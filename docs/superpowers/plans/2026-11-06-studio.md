# Super Ads Studio Implementation Plan

**Goal** Build and verify a local-first production workspace around the authored ad system.

**Architecture** Python owns workflow state and release checks. The loopback browser UI and CLI share that engine. Trusted HyperFrames templates receive validated scene data and FFmpeg verifies and assembles the exports.

- [ ] Reproduce scaffold overwrite, injection, collision, and CTA errors in disposable storage. Preserve the existing CLI.
- [ ] Implement the registry, durable revisions, bounded stage attempts, and approval binding. Exercise the authored branches and adversarial inputs.
- [ ] Connect the four browser views to the engine. Exercise save, reload, preview, review, and download in Chromium.
- [ ] Produce Quiet Hours through the reel workflow. Run the two hook tests, clip handoff, retake, and three-ratio render. Inspect output and preserve evidence.
- [ ] Verify the clean quickstart, run keyless CI and evals, review staged source, and check the pushed SHA.
