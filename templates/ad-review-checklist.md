# Ad Review Checklist

Use this before QA sign-off. Every box must be checked, or the fix must be listed.

## Creative
- [ ] Hook in first 1–2 seconds
- [ ] One punch, repeatable in 5 words
- [ ] Twist by second 5 (15s) or second 8 (30s)
- [ ] Payoff earns the CTA
- [ ] No hard sell before 80%
- [ ] CTA in last 3 seconds only, one action, with where and by when
- [ ] Rewatchable — a second watch reveals something
- [ ] Meme frame named: what gets screenshotted?

## Craft
- [ ] 9:16 vertical first, hero in centre third
- [ ] Safe zones: top 168px clear, text band 168–1330px, min 28px type, about 5 words per line
- [ ] Captions on, 2 lines max, 32 characters per line
- [ ] Sound-off works; sound-on is better
- [ ] Sound -14 LUFS, peaks below -1 dB
- [ ] Thumbnail is deliberate, high contrast
- [ ] 1:1 and 16:9 cuts are reframed, not stretched

## Brand safety
- [ ] Every claim has proof + source
- [ ] Every person has consent proof
- [ ] Every asset (music, font, footage, stock) has a licence
- [ ] No deepfake / face-swap of a real person
- [ ] No misleading price, discount, or "best / No.1" without proof
- [ ] Festive / religious moments handled with respect
- [ ] ASCI / platform rules checked for Meta, YouTube, TikTok

## Accessibility
- [ ] Captions cover every line
- [ ] Contrast is readable on a phone in sunlight
- [ ] No flashing at 3 per second or more
- [ ] No text that appears for less than 0.5 seconds

## Delivery
- [ ] Files named `<slug>-9x16.mp4`, `<slug>-1x1.mp4`, `<slug>-16x9.mp4`
- [ ] Captions .srt included, thumbnail .jpg included
- [ ] Storyboard, shot list, prompts, render steps included
- [ ] Licence / consent notes in the delivery folder
