# Storyboard Template

Copy this table for every ad. One row per shot. 15s is 5–8 shots. 30s is 10–14 shots.

## For 30s, add beats
- 0–2s hook
- 2–8s setup
- 8–20s twist / demo
- 20–27s payoff
- 27–30s CTA

## Styleframe notes
- Hook frame: describe it so a stranger can draw it.
- Twist frame: describe it so a stranger can draw it.
- Payoff frame: describe it so a stranger can draw it.
- Each frame must work as a thumbnail still.

## Sound plan
- Music: track, licence, where it starts and stops
- Sound effects: list per shot
- Silence: which beat is silent, and why
