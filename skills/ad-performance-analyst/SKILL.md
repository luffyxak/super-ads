# Ad Performance Analyst

## When to use
- 3–7 days after launch, with real platform data.
- When a second version, a cutdown, or a new hook is needed.
- When the client asks "did it work?" — answer with numbers, not feelings.

## Workflow
1. Collect the same metrics for every version: hook rate (3-second views / impressions),
   hold rate (watch-through), CTR, CPC / CPM, saves, shares, comments, conversions.
   Do not compare a Reel to a TVC on the same metric without noting the format.
2. Find the drop-off: at which second do people leave? That second is the problem.
   If they leave at second 2, the hook failed. If they leave at second 20, the payoff failed.
3. Read comments, not only numbers. One specific complaint repeated 10 times is a signal.
   "Too long", "can't hear", "where is the price?" — each is a fix, not a feeling.
4. Name what worked: one hook, one frame, one line, one sound. Keep it in version 2.
5. Name what failed: one thing to cut, one thing to change. Do not change five things at once.
   Version 2 changes one variable, so you can learn from it.
6. Write the iteration plan: version 2 hook, version 2 cut, version 2 caption, version 2 CTA.
   Each with a reason tied to the data, not to taste.
7. Hand the plan to the strategist. Do not rewrite the ad yourself.

## Output format
- Metrics table: version, hook rate, hold rate, CTR, saves, shares, comments, conversions
- Drop-off: second, likely cause, fix
- What worked: 3 lines, with numbers
- What failed: 3 lines, with numbers
- Iteration plan: version 2 changes, one variable each, reason per change

## Quality bar
- Every claim has a number and a date range. No "it did well" without a number.
- The drop-off second is named, not guessed.
- Version 2 changes one variable at a time.
- A losing version is killed, not kept alive out of politeness.

## Examples
- Hook rate 28% on version A, 41% on version B — B's hook wins, use B's first 2 seconds.
- Drop-off at second 12 — the demo is too long. Cut the demo to 4 seconds in version 2.
- Comments repeat "price?" — add the price as on-screen text in version 2.

## Anti-patterns
- Judging an ad on likes alone. Saves and shares are stronger for ads.
- Changing the hook, the music, the CTA and the thumbnail at once. You learn nothing.
- Keeping a losing version running because someone likes it.
- Comparing a 15s Reel to a 30s TVC without noting the format difference.
