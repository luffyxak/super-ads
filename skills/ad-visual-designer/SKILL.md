# Ad Visual Designer

## When to use
- After the script, before shooting / generating.
- When the ad looks like a stock video with a logo.
- When colours, type or framing fight the idea.

## Workflow
1. Read the script and the concept board. Name the feeling in one word: warm, cheeky, premium, chaotic.
2. Pick a palette: 3 colours max. One hero colour, one warm / skin tone, one dark for text.
   Diwali: deep maroon / gold / warm cream. Fintech challenger: bold yellow / black / white.
3. Pick type: one display face for the hook, one clean face for captions.
   Large, bold, readable on a phone in sunlight. No thin fonts at small sizes.
4. Pick framing: 9:16 vertical first. Hero in the centre third. Safe zones:
   top 168px clear, text band 168–1330px, min 28px type, about 5 words per line
   (platform UI covers the edges). Frame 0 is the thumbnail.
5. Make 3 styleframes: hook frame, twist frame, payoff frame. Each frame must work as a
   thumbnail. If it does not work still, it will not work moving.
6. Name the light: warm practicals for home / festive, hard daylight for challenger / street,
   soft studio for premium product.
7. Write a look sheet: palette hex codes, type names and sizes, framing rules, light, texture.
8. Hand off to the video director with styleframes + look sheet.

## Output format
- Feeling: one word
- Palette: 3 hex codes + where each is used
- Type: display face + caption face + sizes
- Framing: 9:16 rules, safe zones, hero position
- Styleframes: 3 frames described shot by shot
- Light and texture: 3 lines

## Quality bar
- One frame, no logo, still recognisable as this brand.
- Text is readable sound-off, on a phone, in sunlight.
- Skin tones look real. Gold looks like gold, not yellow plastic.
- The look serves the joke, not the other way round.

## Examples
- Diwali jewellery: warm maroon #7A1F2B, gold #D4A017, cream #FFF6E5. Soft diya light, close-ups of hands.
- Fintech Moonshot-style: black #111111, yellow #FFD400, white #FFFFFF. Hard light, centre framing, deadpan faces.
- Product launch: white background, one hero colour, product centre, fast cuts.

## Anti-patterns
- Five colours, three fonts, and a gradient background. Pick and commit.
- Text at the very top or bottom where platform UI covers it.
- A look that needs a 2-minute explanation. The look is the first second.
- Stock-looking frames with no point of view.
